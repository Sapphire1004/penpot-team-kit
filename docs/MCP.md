# 개인별 MCP 연결

1. 운영자가 만든 본인 계정으로 서버에 로그인합니다.
2. 사용할 디자인 파일을 열고 File → MCP Server → Connect를 실행합니다.
3. 화면에서 제공하는 개인 MCP URL을 로컬 비공개 설정으로 보관합니다. URL에는 키가 들어 있으므로 채팅·이슈·공개 저장소에 붙이지 않습니다.
4. AI 클라이언트에서 연결한 뒤 먼저 현재 파일 ID·페이지를 조회합니다. 쓰기 요청 전에 작업 대상이 맞는지 확인합니다.

서버 주소가 `http://localhost:9001`이면 Streamable HTTP 경로는 `/mcp/stream`이고 개인 URL에는 `userToken`이 포함됩니다. 다른 컴퓨터에서 접속할 때 localhost는 그 컴퓨터 자신이므로 중앙 서버 주소를 사용해야 합니다. URL을 다른 사람과 공유하면 해당 사용자 권한으로 실행될 수 있습니다.

## Claude Code

`examples/mcp-client/.mcp.json.example`을 사용할 프로젝트의 `.mcp.json`으로 복사합니다. 개인 URL을 `PENPOT_MCP_URL` 환경변수로 설정한 셸에서 Claude Code를 실행합니다. `.mcp.json`에는 변수 이름만 남기고 실제 키를 저장하지 않습니다. 변수는 Claude 실행 프로세스에 전달되어야 하며 일반 `.env` 파일만 만드는 것으로 자동 설정되지는 않습니다.

Claude의 `/mcp`에서 `penpot` 연결을 확인하고 다음처럼 시작할 수 있습니다.

> 현재 Penpot 파일 ID와 페이지·상위 보드 목록을 읽어줘. 아직 디자인은 수정하지 마.

환경변수 치환 및 프로젝트 `.mcp.json`은 [Claude Code 공식 MCP 문서](https://code.claude.com/docs/en/mcp#environment-variable-expansion-in-mcpjson)에 따릅니다. 예시 JSON은 정적 검사했고 이 키트의 실제 서버는 MCP initialize·도구 목록·무인증 실행 차단을 검증했습니다. Claude 애플리케이션을 이 시험에서 실행한 것은 아닙니다.

## 여러 프로젝트·여러 사용자

각 계정은 자기 키로 별도 연결할 수 있습니다. 한 계정의 기본 연결은 활성 디자인 파일을 대상으로 하며 로컬 코드 폴더마다 자동으로 다른 파일이 선택되는 구조가 아닙니다. 키를 새로 만들면 이전 키가 교체될 수 있습니다. 만료 시 갱신하고 브라우저 연결도 다시 하세요.

여러 프로젝트에서는 파일·페이지 ID를 프로젝트 설정에 기록하고 `penpot.currentFile.id`와 `penpot.currentPage.id`를 먼저 비교하는 방식을 권장합니다. 이 검사는 실수 방지 수단이고 서버의 계정·팀 권한과는 별개입니다.

디자인 API 실행은 연결된 Penpot 브라우저가 필요합니다. 탭 절전이나 중복 연결로 멈추면 탭을 전면으로 열고 재연결하세요. 필요한 경우 운영자가 `./penpot compose restart mcp`로 서비스만 재시작할 수 있으며 다른 사용자의 MCP 연결도 끊깁니다. 실패한 쓰기 요청을 결과 확인 없이 재실행하면 중복 도형이 생길 수 있습니다.

이 키트의 10인 협업 시험은 디자인 파일의 네이티브 협업 연결 시험입니다. 10명이 MCP로 동시에 같은 파일을 변경하는 시험은 아직 수행하지 않았습니다.
